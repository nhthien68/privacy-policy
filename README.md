# Privacy Policy Website

This repository hosts a lightweight GitHub Pages website for multiple app privacy policies.

## Local Development

Open `index.html` directly in your browser, or serve the folder with any static file server if you prefer.

## GitHub Pages Deployment

1. Push the repository to GitHub.
2. Open repository `Settings`.
3. Go to `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select:
	- Branch: `main`
	- Folder: `/(root)`
6. Save the settings.

Your site will be available at:

https://<github-username>.github.io/privacy-policy/

## URLs

- Homepage: `https://<github-username>.github.io/privacy-policy/`
- Quay So: `https://<github-username>.github.io/privacy-policy/app-quay-so/`
- Can Lua: `https://<github-username>.github.io/privacy-policy/app-can-lua/`
- Battery Alert: `https://<github-username>.github.io/privacy-policy/app-battery-alert/`

## Adding New Apps

Create a new folder like `/new-app-name/index.html` and link it from the homepage.
